# 검증 기준

- 설치 후 명령 진입점과 기본 테스트가 실제로 실행된다.
- 같은 제목의 작업이라도 서로 다른 업무 항목으로 등록할 수 있다.
- 검증 템플릿에서는 버전 또는 분야가 다르면 같은 함수도 별도 작업이다.
- 잘못된 날짜, 검증 템플릿의 중복 대상, 권한 위반은 저장되지 않는다.
- NAS가 없을 때 로컬 입력은 보존되고 전송 대기로 표시된다.
- 재연결 후 다른 PC에서 변경을 볼 수 있다.
- 두 편집자의 프로젝트 정의 충돌이 조용히 덮어써지지 않는다.
- 담당자는 타인의 진행 결과를 변경할 수 없다.
- 손상된 스냅샷을 받아도 로컬 데이터가 훼손되지 않는다.
- 엑셀 가져오기 전 중복·누락을 확인하고 원본 건수와 집계를 대조한다.
- 실제 PC와 NAS 환경에서 백업 및 복구를 시험한다.

각 항목은 해당 기능이 구현된 후에만 검증 완료로 표시한다.
