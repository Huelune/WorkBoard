# 저장 및 동기화 설계

이 문서는 구현 계획이다. 현재 동기화 코드는 없다.

1. 각 PC의 SQLite에 업무 변경을 먼저 트랜잭션으로 저장한다.
2. 같은 트랜잭션에서 전송 대기 항목을 기록한다.
3. NAS 연결 시 프로젝트 정의와 사용자별 진행 데이터를 JSON 스냅샷으로 공유한다.
4. 프로젝트 정의는 편집자가 짧은 잠금과 기준 개정 번호 비교로 게시한다.
5. 담당자는 자신의 공개 진행 스냅샷만 게시한다. 다른 사용자의 진행 데이터는 조회 전용이다.
6. 파일은 임시 파일에 모두 기록한 후 같은 파일 시스템에서 원자적으로 교체한다.
7. 수신 시 schema_version, revision, 내용 형식과 해시를 검사하고 로컬 트랜잭션으로 적용한다.
8. 기준 개정 번호가 다르면 자동 덮어쓰지 않고 충돌을 표시한다.
9. NAS 실패는 로컬 저장을 취소하지 않는다.
10. 로컬 SQLite 파일을 NAS에 두거나 파일 전체를 복사하지 않는다.

강한 실시간 협업이나 중앙 권한 통제가 필요하면 서버 저장 방식으로 재검토한다.
