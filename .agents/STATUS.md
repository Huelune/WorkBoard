# WorkBoard 현재 상태

기준일: 2026-11-17
기본 브랜치: `main`

## 현재 구현

- 독립 Python 패키지, `workboard` CLI 진입점, UUIDv4 업무 항목 ID 규칙.
- 제품·저장 설계와 익명화된 예시.

엑셀형 화면, SQLite 저장, NAS JSON 동기화, Codebeamer API 연동은 아직 구현되지 않았습니다.

## 검증 근거

- 프로젝트 기반 구성 시 CLI 실행과 단위 테스트 2개 통과를 확인했습니다.
- 이 문서를 읽을 때는 최신 브랜치·커밋·테스트 결과를 다시 확인하세요.

## 다음 작업의 출발점

`docs/product-plan.md`와 `docs/storage-design.md`의 미결정 사항을 실제 업무 목록의 익명화된 예시로 확인한 뒤, 공통 업무 모델과 로컬 저장 흐름을 구현합니다. 작업 우선순위와 상태는 프로젝트 전용 Notion 백로그 및 실제 사용자 요청을 기준으로 확인합니다.
